# 看護師向けタスク・動線管理ツール (※名称は仮です)

医療現場の人手不足や、多忙なマルチタスク・突発的な割り込み業務による看護師の疲弊を軽減するためのタスク・動線管理アプリケーションです。位置情報と細粒度な状態遷移を組み合わせることで、現場の動線最適化と認知負荷の削減を目指します。

## 🏥 背景と解決したい課題
* **物理的な疲弊の軽減**: 物品の取り忘れや非効率な移動により、病棟内を1日1万歩以上歩行する無駄な動線を解消します。
* **認知的負荷とインシデントリスクの低減**: 業務中断に伴う「次に何をすべきか思い出すコスト」を最小化し、医療ミスやヒヤリハットを防ぎます。
* **心理的孤立の防止**: 現場の負荷状況（Stress Level）を視覚化し、特定のスタッフへの業務集中を防ぎ、適切な応援要請を促します。

## ✨ コア機能
* **細粒度ステータス遷移（8段階）**: 処置と記録それぞれの「開始・中断・再開・完了・未実施（Skipped）」を厳密に制御します。
* **「ついで」レコメンド**: 部屋IDを選択時、同室内の低優先度タスク（ゴミ捨てや物品補充など）を最前面に提示し、無駄な往復を削減します。
* **割り込みレジュームナビ**: 処置や記録の中断時に理由をスタックし、対応終了後に再開対象のタスクを最優先で通知します。
* **タイムライン管理と個人付箋**: 時間軸でのタスク可視化とドラッグ＆ドロップ操作に加え、思いついたメモを追加できるSticky Note機能を搭載しています。
* **負荷の可視化とログ出力**: タスクの詰まり具合からストレスレベルを算出してマップ上に表示し、業務改善解析用のJSONログを出力します。

## 🎨 UI/UXのコンセプト
* **Zero-State（ゼロ・ステート）**: 今必要な情報以外は極力隠し、迷わせないUI設計。
* **One-Hand Action**: 片手が塞がっていても親指一本で操作可能な動線。
* **Haptic Feedback**: 音が出せない夜間環境などに配慮した、振動による通知とフィードバック。
* **状況に応じたカラーパレット**: 集中型（Vital & Focus）、安定型（Serene & Calm）、夜間対応型（Dark Mode）の3モードを切り替え可能。
